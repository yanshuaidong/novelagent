## 品级金字塔

功法等级为金字塔结构，越往上越窄，越难企及：

| 层级 | 稀有度 | 说明 |
|------|--------|------|
| 一品—三品 | 百里挑一 | 塔底，坊间好手、护卫差役 |
| 四品—六品 | 千里挑一 | 塔身，江湖骨干、镖局统领 |
| 七品—九品 | 万里挑一 | 塔身收窄，称雄一方（如王承恩八品、魏忠贤九品） |
| 九品上 | 凡人悟道天花板 | 凡人武道极致，触大宗师门槛 |
| 大宗师 | 塔尖 | 半神，个人战力可抵万人之军 |

- 大明皇室仅太祖、成祖达大宗师；嘉靖据传修至九品上，冲关失败。
- 当世五位大宗师：西湖白素素、武当张君宝、东瀛宫本天藏、西域鸠摩罗什、南疆古月方元。

## 天赋测试

弘文馆入学典礼以**测试石**测武道天赋：双手置于石上，石发不同颜色之光。

### 天赋色（品质）

六档，由低到高：**青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀**

- 与灵魂绑定，决定未来品级上限。
- 天赋色定大档，光强光弱定同档内的潜力高低（如青铜大概率四品；光强者上浮，光弱者下浮）；星耀基本预定未来九品。
- 弘文馆测试主要预测四品至九品潜力。

| 天赋色 | 大致预期品级 |
|--------|-------------|
| 青铜 | 四品 |
| 白银 | 四品上～五品 |
| 黄金 | 五品 |
| 铂金 | 五品～六品 |
| 钻石 | 七品～八品 |
| 星耀 | 九品 |

### 同档辨强弱

测试石辨**主色**定天赋色。**同一颜色，光越强、越纯、越亮，天赋越高；光越弱、越暗、越杂，天赋越低**。不设子等级，比较时直说即可——「同是铂金，云朗光强，某同学光弱。」

若光中透更高一阶的颜色，说明已摸上下一阶门槛，仍按主色定档，不作另立名目。

**示例**：
- 铂金色，光强而纯 → 同档上乘（如周云朗）
- 铂金色，光弱而杂，掺杂黄金色、青铜色杂色 → 同档下乘
- 铂金色，光强至极，已透钻石光 → 摸上钻石门槛，仍按铂金定档

### 双完美星耀（特例）

极少数体质可二次启动测试石，两次皆星耀且光皆至极。**双星耀**意味着丹田两色交融、修炼互不干扰；外人探查无法分辨，只见一色，仅本人自知两色。穿越者体质，前无古人后无来者。
