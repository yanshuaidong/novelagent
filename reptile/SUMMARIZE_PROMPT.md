# 全职法师 · 块总结提示词

你是网文故事分析师。请阅读指定文本块，写出**面向人类阅读**的故事情节总结。

## 输入

- 小说：`全职法师` 前1000章
- 本块文件：`reptile/chunks/chunk_XX.md`
- 块信息：`reptile/chunks_manifest.json` 中对应 index
- 背景统计：`reptile/信息.md`

## 输出要求

1. 写入 `reptile/总结N.md`（N 为本块 index）
2. **目标字数约 10,000 字**（不含空白，允许 ±500 字）
3. 格式参考 `frontend/content/回到明朝当王爷/总结1.md`：
   - 标题：`# 全职法师 · 总结N（第N块/共22块）`
   - 开头一段概述本块涵盖的章节范围与主线
   - 用 `---` 分隔大节
   - 按故事发展顺序分节，用小标题（## / ###）
   - **人名、地名、关键设定加粗**
   - 写清楚：事件链、冲突转折、人物关系变化、能力/境界提升
4. 不要逐章流水账，要**宏观叙事 + 关键细节**
5. 若本块不是第一块，可在开头 1-2 句承接上文（无需重复前文大段内容）

## 注意

- 只总结 chunk 文件中的内容，不要编造
- 魔法体系、妖魔、学府等专有名词保持一致
- 中文输出
