# 熹宗实录故事摘要（续二）

> 据《明熹宗悊皇帝实录》第三十一至第三十三册（卷之六十三至六十七），时间跨度约自**天启五年九月**（1625）至**天启六年二月**（1626）。

---

## 一、门工加恩与阉党荣宠

天启五年**九月甲寅**重阳节，**皇极殿**升梁告成，朝廷大加恩赏：

| 对象 | 恩赏 |
|------|------|
| 内阁 | **孙承宗**、**顾秉谦**进中极殿大学士；**周如磐**、**丁绍轼**、**黄立极**、**冯铨**晋文渊阁大学士，各荫一子 |
| 内臣 | **王体乾**、**魏忠贤**、**李永贞**等加恩三等；忠贤以「缉事有功」再加赏、荫弟侄为都督同知 |
| 朝臣 | **林尧俞**、**高第**、**赵彦**、**白所知**等赉银币；**杨梦衮**、**崔呈秀**、**李养德**、**吕浚**等科道部属加升二三级 |
| 锦衣 | **田尔耕**加少师兼太子太师；**杨汝敏**等十员各升一级 |

同日，**魏广微**辞免陵工加恩不允；**叶向高**亦奉旨祗受，不必逊辞。

## 二、柳河败衄与马世龙之罪

**九月壬子**，辽东总兵**马世龙**遣副总兵**鲁之甲**、参将**李承先**渡河袭锦州，败殁。

| 环节 | 内容 |
|------|------|
| 起因 | 降虏生员**刘伯镪**自虏中归，声言四王子在锦州兵不满三百，诱马世龙渡河 |
| 败局 | 水兵大船不至，济以渔舟往返四昼夜；虏酋伏兵掩击，二将战死 |
| 朝议 | 上责马世龙轻进丧师；喻安性「绝不与闻」姑策励供职；**孙承宗**引疾乞罢，上勉留 |
| 后续 | 兵科**李鲁生**请断祸本、坚壁清野；兵部催**杨麒**等到任勘明；**徐日久**因先劾世龙被削籍 |

此战为关门哨将巡河陷没，朝野震动，枢辅与镇臣之责成为言路焦点。

## 三、孙承宗清兵省饷与乞归

**九月庚戌**，枢辅**孙承宗**覆清汰兵马粮饷：

- 汰过官兵一万七千四百三十七员、马骡五千六百四十九匹，岁省饷银五十四万一千六百三十五两，并省米豆草束通计六十八万余两。
- 关门实在官兵十一万七千三员，岁需饷银二百四十九万四千七百三十六两。
- 巡抚**喻安性**再裁八十三员，岁省银三万四千六百八十五两。

**孙承宗**屡疏乞归。至**十一月庚寅**，上始许之：加特进光禄大夫，荫一子中书舍人，驰驿回籍，赐银一百两、彩叚四表里、大红纻丝坐蟒一袭，谕善自调摄以需召用。

## 四、东林案定谳：《移宫》罪名与杨涟等爰书

此段为**天启五年秋**政治清洗之高潮。

### 贾继春翻案

**九月甲寅**，御史**贾继春**疏发**移宫**旧事：指**杨涟**、**左光斗**、**魏大中**等串通**王安**，倡垂帘之说，逼辱**康妃**与皇八公主，并受贿营脱**熊廷弼**。

上震怒，下旨：

- **熊廷弼**已处决传首九边；
- **杨涟**、**左光斗**、**周朝瑞**、**魏大中**、**袁化中**、**顾大章**、**汪文言**等送法司研审，限十日内问结，仍追赃；
- **惠世扬**扭解来京从重究治；
- 罪状及守正诸臣疏揭、明旨，著史臣编辑成书颁行天下。

### 爰书成案

**九月丙寅**，刑部**李养正**等呈爰书：坐**顾大章**大辟；杨涟等虽瘦死囹圄，姑从轻典，仍戮尸都市；未完赃银严提家属追比。

**镇抚司**复奏：汪文言即汪守泰，与诸奸结党行私、庇护熊廷弼、受巨万重赂；爰书并招词宣付史馆，垂信万世。

### 后续清洗

秋至岁末，言路连章追劾「东林遗奸」：

- **孙居相**、**史记事**、**南居益**、**崔景荣**、**李孔度**、**夏之令**等削籍追诰；
- **陈子壮**、**陈熙昌**父子以试录「庸主失权、英主揽权」等语削籍；
- **胡永顺**、**陆师贽**等以诬陷前官被黜；
- **朱世守**、**刘策**、**陆完学**、**王惟俭**、**唐世济**、**刘可法**、**胡世赏**、**金世俊**、**李宗延**等迭去；
- **卢承钦**请将党人姓名罪状刊刻成书榜示海内——旨令部院会同九卿科道查确集议。

## 五、经略易人：高第出关、孙承宗归里

### 高第经略

**十月辛巳**，命兵部尚书**高第**以原官经略辽东、蓟镇、天津、登莱等处军务，赐尚方剑、坐蟒玉带银币，即日赴关。

上谕高第：封疆重权在经略，文武将吏一听提衡，机宜不从中制；同心共济，不得狥情废法、偏听生奸。

**高第**到关后请申明节制，得旨军法从事，旌旗改观。

### 孙承宗交卸

**十一月丙辰**，**孙承宗**条奏关门任内军务分款具报；又请速定镇道去留：

- **刘诏**照旧供职；
- **马世龙**戴罪立功，出关防御；
- **喻安性**以病冠带闲住，辽抚裁革。

**高第**奏西虏**歹青**被杀、**都令**挟索偿命银，款局未结，请严敕讲处；上命枢辅归、辽抚准病，经督同心料理。

## 六、皇子诞生、大赦与容妃册封

### 皇第三子生

**天启五年十月初一日**，**皇第三子**生，**容妃任氏**出。是日：

- 孟冬亲享太庙；
- 遣官祭告南郊、北郊、太庙、社稷；
- 赐辅臣、讲官银币；
- 容妃父**任景春**授锦衣卫正千户。

### 覃恩大赦

**十月庚子**，以皇子生颁诏大赦天下。诏款浩繁：蠲免天下宿逋一年、漕折再免一年、盐课拖欠尽蠲、税契暂复、纳银充附、优免京师房号银三月、释徒流编发、矜疑免死、武职比试住俸皆宽，等等。

遣翰林等官赍诏分赴各省直、朝鲜、诸王府开读。

### 册封皇贵妃

**十一月丙午**，皇子弥月受贺；**容妃任氏**进封**皇贵妃**，遣英国公**张惟贤**持节，大学士捧册行礼。

**皇极殿**竖柱升梁，首辅**顾秉谦**加尚书俸、赐坐蟒；辅臣**丁绍轼**、**黄立极**各赐坐蟒。

## 七、登莱抚镇之争与毛文龙

### 武之望请制毛文龙

**九月辛亥**，登莱巡抚**武之望**奏：毛文龙专制海外、糜饷饰功、擅权横恣，请设重臣居石城、广鹿适中之地节制两镇，并设监督道臣查核钱粮功罪。

礼科**叶有声**骇然：旅顺游击**张攀**守旅顺，东镇**张继善**等尽撤其民兵，空堡贻患。

上命两镇照原分信地各守，**王国祯**佐枢久不到任申饬。

### 互参升级

**十一月甲寅**，毛文龙陈海上情弊六款，诋登抚妒忌阻挠；**武之望**奏辩，言文龙移文揶榆、诋毁节钺。

吏部议：登抚与镇臣形迹已分，**武之望**调南京别衙门，员缺另推；**袁可立**起为添设兵部右侍郎。

**十二月丁丑**，山东巡抚**吕纯如**言：毛帅为奴所忌，宜安之以重封疆；登抚宜优之以存纪纲，不可因同事睚眦遽撤。

### 献俘真伪与朝鲜变局

- 兵部驳毛文龙解俘：活夷三十一名中途换回五名，「直同儿戏」，旨令一并献俘。
- **十二月**，文龙再献俘夷，登抚**武之望**奏：累累解京劳费驿递，请除头目外余就彼处论功。
- 朝鲜**李晖**逆党**李适**等起兵，**韩润**等勾奴；文龙移兵**云从岛**（须弥），铁山空虚，鲜人疑逼。
- 兵部覆：抚镇不和为大利，韩润等著朝鲜自行处分，登莱巡抚与江东同心共济。

## 八、西南：蔡复一殉节、朱燮元会剿

### 蔡复一卒于军中

**十一月甲戌**，总督川湖云贵**蔡复一**卒于**平越**军中。

监军御史**傅宗龙**疏其鞠躬尽瘁、贫无以敛；诏予祭葬，赠兵部尚书，录一子国子生，谥**清宪**。

### 朱燮元请饷会剿

**十月癸未**，川湖总督**朱燮元**陈会剿机宜：滇、蜀、黔、粤西四面合围，请敕下先付一百万两经营。

户部覆：天启五年四川应角银十九万三千余两听督臣通融接济，从之。

### 贵州屯守方略

**十一月丁亥**，贵州巡按**傅宗龙**条上屯守方略：以守为屯，沿河设寨，需兵四万八千人、岁饷八十余万、三年为期——下部议。

**十一月**，蔡复一报征剿**天保阿秩**等，攻破一百七十四寨，斩级二千三百五十。

## 九、财政、盐政与三殿大工

### 户部救急诸议

户部尚书**李起元**条议：

- 暂复榷税、纳银充附、广开屯田、申饬茶马、申明盐法；
- 查征倭征播加派已蠲而仍带征者；
- 蓟镇、密云、永平、昌平、易州秋季饷银如额兑发。

### 两淮盐法之争

**董应举**总督钱盐，条「立纲」「铺纲」利害；户部**李起元**主盐臣铺纲之议，斥督臣新纲为「误钱法又坏盐法」；上然部议，吴惟顺等付盐臣追赃。

**崔呈秀**议江西行盐：南赣二府属粤、吉安归淮，淮商先贮引银四万二千五百两助大工。

### 大工与助工

- 诸藩府、文武臣工捐俸摉括助建**皇极殿**；**黄克缵**督瑞王府工；
- **霍维华**议云雾山开采佐殿工；
- 工部追**郭振明**、**王昇**冒支陵工银；**李承恩**、**王昇**削爵，子粒还官助工；
- 殿工物料照例免税；商人税阻滞请免税，从之。

## 十一、丁绍轼去位与阁臣更迭

**十一月壬子**，大学士**周如磐**三疏乞归，上许之，遣行人护送，加赐银一百两、彩叚四表里。

**十二月癸巳**，大学士**丁绍轼**三疏乞休，命鸿胪寺宣谕即出。

**丁绍轼**去位前后：

- 江西道御史**吴裕中**以乡戚之情诋辱丁绍轼，旨杖一百、革职为民——比之**熊廷弼**同肺肠；
- 赵胤昌责其议马世龙去留反覆；上谕次辅和衷任事，不必因人言介意。

**十二月辛卯**，**王在晋**改兵部尚书；**阎鸣泰**、**袁可立**升兵部添设侍郎；**李嵩**升登莱巡抚。

**周如磐**十二月**甲申**卒，赠少保，谥**文懿**。

- **十一月己酉**，锦衣卫缉获妖僧，词连扬州知府**刘铎**；旨扭解来京与妖僧对理。
- **十二月丙申**，诰敕房中书**吴怀贤**读杨涟**二十四罪**疏旁加批点，下镇抚司狱，竟毙杖下。
- **左都御史王绍徽**条宪纲十款（嘱托、仓库、风俗、武备、驿递、盗贼、贪官、套荐、勘合、奢侈），旨责成巡方御史实行。
- **惠世扬**十二月庚子下镇抚司：借汪文言结王安、倡议移宫，送法司从重拟罪。

## 十四、天启六年正月：奴犯宁远与「宁远大捷」

### 战前形势

**正月庚戌**，经略**高第**奏：奴贼希觊**右屯**粮食，约正月十五前后渡河。

上谕：山海逼近，经督镇臣殚心料理，画地分守，毋轻率躁进、毋观望不前；逃者尽斩。

**兵部尚书王永光**请调遵化、宣镇、三屯、附近督抚兵马入援；**阎鸣泰**协理京营，议固守宁远、觉华设伏；**罗尚忠**、**陆文献**、**薛国观**、**王应熊**等连章条守援、清野、联虏、京营、冻粮诸策。

### 宁远被围

**正月二十三日**，大营达子到**宁远**，扎营一日。

**二十四日寅时**，贼攻西南城角；道臣**袁崇焕**缚柴浇油、搀火药烧贼战车，又缒健丁五十名焚其攻具。贼退后差人报信。

**二十五、二十六日**，贼复攻；城中用**红夷大炮**及火器，前后伤虏数千，毙头目及酋子一人。贼拔营退至**龙官寺**一带，约五万余骑。

**觉华岛**：总兵**满桂**开南门追剿；贼分兵攻岛，焚掠粮货。岛岸冰凿开，贼不能过海。

### 朝廷嘉奖

**正月二十六日**旨：

- 嘉**袁崇焕**、**满桂**、**赵率教**、**左辅**、**祖大寿**、**朱梅**等协心御敌；
- 户兵二部发银十万两充犒赏；
- 督臣出关应援，不得坐视宁远为孤注。

**二月乙亥**，升**袁崇焕**为都察院右佥都御史，专理军务，照旧驻劄宁远。

### 西虏与援兵

- **赵率教**率兵御西虏犯**平川三山堡**等处，斩级八十三，获达马一百五匹；
- **杨应乾**追斩二十级、获马七十匹；
- 满桂、赵率教实授总兵，加都督同知；**周守廉**逃兵待经督奏报定夺。

### 奴退过河

**二月初九日**，贼分三枝自**三岔河**渡河；**初十日**尽数过河东归。

大学士**顾秉谦**等奏：此役遏十余万强虏、振八九年积颓，关外第一胜仗；然兵力单虚、西虏窥伺，安不忘危，不可以小胜自满。

上命亟修战守，以备卷土重来。

## 十五、《三朝要典》开馆与正月朝政

**正月戊午**，上谕礼部：杨涟、左光斗等借**梃击**、**红丸**、**移宫**三案贪定策之勋；今允部院科道请将节次明旨及诸臣正论编辑成书颁行天下，名之曰**《三朝要典》**，新春开馆纂修，以昭**三朝慈孝**。

同月其他要事：

- 差官追**王之采**、**周宗建**、**熊明遇**、**杨涟**、**左光斗**、**顾大章**等家属赃银助大工；
- **范凤翼**、**姜习孔**、**孙绍统**、**傅梅**、**吴鸣虞**等以邪党削籍；

## 十七、此段历史脉络（简括）

**天启五年九月至天启六年二月**，朝政呈现「大典恩赏」与「门户屠戮」并行的剧烈反差：一边**门工**告成、**皇子**诞生、**大赦**覃恩、**容妃**册贵；一边**贾继春**疏发**移宫**定案，**杨涟**等爰书颁行，**东林**名籍几尽，**卢承钦**请刊党籍示天下。边事则**马世龙**柳河丧师、**孙承宗**清兵省饷后归里，**高第**继经略而款局未结；**毛文龙**与**武之望**互讦，登莱、东江两线愈难协同。西南**蔡复一**殉节黔中，**朱燮元**仍索百万军饷会剿。至**天启六年正月**，奴酋大举围**宁远**，**袁崇焕**以红夷大炮挫其锋，**满桂**、**赵率教**等并力守战，贼焚**觉华**粮储后东归——为辽事八年来首胜，然关门援兵迟滞、文武不和之弊未除，**《三朝要典》**又开馆定谳，国势在「捷音」与「党祸」之间继续滑向更深的内耗。

## 二十二、袁崇焕经略宁远与满赵不和

**三月**起，**袁崇焕**条善后：以辽人守辽土、汰兵为八万、宁远添辅城、请马匹银二十万、铅火药银五万等；辞升职请终制，不准。

**四月**起，**满桂**与**赵率教**因宁远分功、援兵不入城等事积怨；上屡谕「协力同心」。**袁崇焕**参满桂骄蹇、城工随修随倒；**王之臣**亦请留满桂。

**六月**，旨准**满桂**暂回府候推别用，宁远防务归**左辅**；**赵率教**请移镇宁远拒敌，从之。九卿科道会议督抚去留：多数主张**关内关外分任**，**袁崇焕**专任关外恢复，**王之臣**还朝或协理京营；责两臣捐去成心，缓则各修防御，急则互相应援。

**袁崇焕**又陈：西虏**虎酋**遣**桑昂寨**助兵；哈喇慎等宜抚不宜纵；奴报四月再犯，坚壁清野、分守五城。**毕自肃**、**孙元化**赞画军前。

## 二十八、此段历史脉络（简括）

**天启六年二月下旬至闰六月**，在宁远大捷余波之上，朝廷一面**大赏功臣**、**晋袁崇焕**为辽抚、**改王之臣**为督师，一面**强遣六内臣**出镇山海，**阁部台省**交章力谏而不果。门户之狱则**惠世扬**伏法、**熊廷弼**传首、**周顺昌**/**黄尊素**/**周宗建**/**缪昌期**/**李应昇**等相继毙于诏狱，**《三朝要典》**告成颁行，**天鉴录**等私书禁毁。边事则**袁崇焕**筑城造炮、联西虏制奴，**满桂**与**赵率教**不和致良将暂去；**毛文龙**牵制之功屡被科道质疑；**觉华**、**喜峰**、**蓟昌**防务日紧，奴报**四月**/**八月**再犯。西南**奢寅**死而**鲁钦**溃亡、**安邦彦**屡挫复起，黔饷告急。与此同时，**王恭厂**/**朝天宫**火灾、**太子**之殇、**京师**再震、**灵丘**巨震与霪雨修省之诏，与**三殿**搜括、**魏忠贤**封**肃宁伯**及**生祠**之议交织——捷功未固，内耗愈深，关内外「文武不和」之痼疾，仍是此段史事的主线。

## 四十三、此段历史脉络（简括）

**天启六年七月至十二月**，朝廷在**皇极殿告成**的庆典氛围里，将**魏忠贤**推至**上公**、**宁国公**、**肃宁侯**并赐**生祠**之巅峰，同时以**《三朝要典》**颁赏、**黄山吴养春案**追赃、**刘铎**/**周起元**/**门克新**等案，继续涤除「东林」与「逆犯」余孽。边事则因**奴酋哈赤**死、诸子争位，出现「恢复可期」之议：**袁崇焕**主守不战、屯田筑城、遣喇嘛间谍，**王之臣**则倡据广宁、绝和议、合关宁——二人款守异同、机宜密奏，仍是督抚不和之延续；**满桂**镇榆关、**赵率教**守宁远，霖雨塌城后并力修补。**毛文龙**百万请饷未充，东江牵制与登莱裁兵之辩不绝。西南**王瑊**匀哈告捷而**闵梦得**索饷百万，黔事权归督臣。**宣大毛乞炭**犯边、**张承宪**战死，复引内臣出镇宣大之议。财政上漕运艰涩、鼓铸助工、岁会严核与畿辅赈粥并行——大典恩赏与门户追赃、边捷声言与款守之争、三殿告成与辽东未复，构成此段史事的内在张力。

### 王之臣去、袁崇焕专关外

**二月己亥**，督师**王之臣**引疾，加**太子太保**解任回部。

**二月癸卯**，吏兵会议关宁：关门兵马听**袁崇焕**调度；**满桂**山海、**赵率教**宁远；道臣**王应豸**理榆关。**黄立极**拟谕强调督抚内臣「琴瑟笙竽相调」。

### 皮岛遣内臣

**二月乙巳**，特命**胡良辅**总督登津镇守海外、**苖成**副镇守、**金捷**等中军，驻**皮岛**督饷运、查钱粮；发御前节省银五万、大炮火器助**毛文龙**。谕「海外兵贵精、饷贵实」。

### 东江危机

- **毛文龙**请东江南官**徐鸣泰**等照辽例支俸。
- **奴围铁山**、犯朝鲜；**袁崇焕**发水兵声援，遣方金纳贻书促奴撤兵。
- **高万重**临敌脱逃、**石城岛**游击席卷岛货西逃；**许可徵**请正法。

### 其他

- **黄山**派买激变：**吕下问**株连无干，徽州几酿大变；后分**吴养春**山入官、百姓原业照旧。
- **瑞王**、**惠王**、**桂王**陆续之国；**冯嘉会**卒，赠少师。

### 贵州与西南

| **尹同皋** | 水西安位、**安邦彦**渡河，黔局再变 |

### 门户与诏狱

- **王之采**（原兵部右侍郎）**四月**下镇抚司，追赃八千两；**乙卯**死于狱。
- **孙慎行**谪戍宁夏；追**熊廷弼**赃、**高攀龙**子**世儒**拟徒配。
- **郝土膏**追赃拟徒纳赎；**陈维新**等以门户削籍。

### 经略与筑城

**三月辛酉**，**袁崇焕**辞重任不允；谕「守为正、战为奇、款为旁」。

**三月**，**王之臣**奏抚赏弊、**中前所**/**铁场堡**/**芝麻湾**犄角筑城；班军五万通融拨用。

**四月**，**王之臣**复为兵部尚书、**太子太傅**；**霍维华**署部事。

### 奴警东援

**四月庚子**，**李嵩**奏朝鲜义州陷、平壤黄州溃，君臣播越；兵部令**袁崇焕**乘奴远掠捣巢。**冯嘉会**卒后，**王之臣**、**霍维华**署事。

## 四十七、五月：锦州被围与宁锦大战

### 奴犯锦州

**五月**初，奴酋**黄台吉**（实录称「奴子」）大军东援朝鲜后西犯：**五月己卯**渡河，哨至闾阳驿，直窥锦宁。

| 环节 | 内容 |
|------|------|
| 围锦 | 贼围**锦州**二十五日；内臣**纪用**与将官约「出城杀贼赏五十两」，人人争战 |
| 援兵 | **满桂**、**尤世禄**东援；**笊篱山**夹攻，斩馘有限而振军气 |
| 调兵 | 昌平、宣大、真定、永平、蓟镇援兵数万赴关；**满桂**出援，**侯世禄**镇山海 |
| 策略 | **袁崇焕**以寡兵抄后、水师绕后、西虏**贵英恰**等助战；坚壁清野，不轻弃四城 |

### 袁崇焕引疾与款议之争

**五月庚辰**，**袁崇焕**长疏：「守为正、战为奇、款为旁」；斥议款者，请**九卿科道**会议恢复方略，并引疾。上谕「谈款误不小」、疆事方殷不许乞身；**赵率教**候**杜文焕**至日交代。

**李鲁生**疏请联**虎酋**攻奴；**王之臣**、**袁崇焕**各陈款不足信、须我先能自用——上命中外熟议。

### 粮饷与援滞

- **郭允厚**、**刘徽**疏陈关宁兵马米豆册籍参差，饷司分关内外。
- **李嘉训**等援兵逗遛、**孙祖寿**拥兵不战，旨策励供职。
- **佟惟奇**奸细案：凌迟，**魏忠贤**再加荫。

### 奴退

**五月**末，报奴回巢；**王之臣**奏以逸待劳、伏兵击惰。**六月**实录无条目（卷八十四注「六月无」）。

## 四十八、七月：宁锦献俘与魏忠贤封伯

### 锦州大捷叙功

**七月乙丑**，上虽**不豫**，仍下旨特简**王之臣**赐尚方剑、星驰督师榆关兼抚辽镇，节制关宁。

**七月丙寅**，**纪用**献俘活夷五十九名；**初九日**献俘，上免临御，遣臣祭告郊庙后正法。

| 对象 | 恩赏（摘） |
|------|------|
| **魏忠贤** | 比照**宁晋伯刘聚**例，弟侄封**安平伯**世袭，岁禄千一百石、赐诰券 |
| **魏鹏翼**（嫡孙，年四岁） | 加**少师**，晋**安平伯** |
| **纪用** | 加恩三等；**刘应坤**、**王体乾**、**李永贞**等内臣并荫赏 |
| **王之臣** | 加**少傅**、**太子太师**；**霍维华**升兵部尚书 |
| **满桂** | 加**太子太师**；**赵率教**加**太子少傅** |
| **阎鸣泰** | 加**少傅**，协理京营戎政 |

**黄立极**等疏请封**魏忠贤**「大晋公」；上以宁晋例封**安平伯**。

### 袁崇焕罢归

**七月辛未**，**陈维新**疏发**袁崇焕**谈款、援锦迟滞之失；旨追**谈款之误**、**李嘉训**等革任。**袁崇焕**准回籍；**霍维华**请以己荫移赐**袁崇焕**，上斥其「移荫市德」。

### 王之臣出关

**七月庚午**，**王之臣**奏募西兵、调**江鲲**、**官惟贤**等赴辽；请饷银十万犒赏，许之。

### 其他

- **孙承宗**改吏部尚书（前段已叙）之脉延续：**刘诏**升兵部右侍郎总督蓟辽。
- **杨肇基**等延镇捷；**洗马林**、**干儿骂**等西虏挫。
- 谕禁「讪上谤政」：方逢年、**阮大铖**等被点名；**贺逢圣**削籍。

## 五十一、此段历史脉络（简括）

**天启七年正月至八月**，国势在「大典告成」与「边陲再捷」的凯歌中急转直下：**三殿**（皇极、中极、建极）二年告竣，**信王**成婚、**瑞惠桂**三王就国，**魏忠贤**一门封**侯**/**伯**（**安平伯**、**魏鹏翼**少师）、**客氏**与内臣**涂文辅**/**崔文昇**/**胡良辅**分掌京储、漕运、东江，生祠遍天下；门户则**王之采**毙狱、**孙慎行**戍边、考官**贺逢圣**/**刘先春**等以「讪上」「门户」削黜，**阮大铖**却得召用。边事五月**锦州**被围二十五日，**纪用**/**满桂**/**尤世禄**/**袁崇焕**内外夹攻，奴退后**七月**献俘，**王之臣**再出督师；然**袁崇焕**以「款」议与援锦迟滞见罪回籍，**霍维华**掌兵部，**崔呈秀**终据枢垣。八月恩赏登峰而**上疾大渐**，**乙卯**崩于**乾清宫**，遗诏立**信王**——七年之治，以阉党极盛、宁锦再胜与**熹宗**早逝而收束，辽东恢复之梦与门户之祸，俱留与后继之君。
