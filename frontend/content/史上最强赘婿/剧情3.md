# 剧情3

沈浪与金木聪合著的《金瓶梅之风月无边》在春色书坊掌柜邓先的操持下，紧锣密鼓地印刷制作。邓先起初对这书的销路并无信心，毕竟作者"浪陵笑笑生"毫无名气，定价六十铜币还比大才子祝文华的《鸳鸯梦》贵了两成。沈浪却志在碾压祝文华，不仅要用文字和插图取胜，还要在营销上出奇制胜。他亲手绘制了极其逼真的彩色大幅海报，画面上西门大官人、祝文山和西门纤纤的动作和姿态尺度极大，在当世前所未有，视觉冲击力爆炸。

祝文华的《鸳鸯梦》下册上市当天，各大书坊排起长队，场面火爆。然而沈浪的书摊就摆在对面，当那巨幅彩色海报一展开，瞬间引爆全场——逼真的西洋写实画风让所有男人挪不开眼睛。有学问的读书人发现这本书文字造诣极高，洞察世情；没学问的看肉戏也觉得细腻入微；不识字的只看插图就已满足。一时间，全城十三处书摊销售狂潮，仅兰山城一天就卖出三千余本，是祝文华销量的数倍。

祝文华得知后羞愤交加，更发现书中角色"祝文山"——一个落魄贵族、沦为男宠的形象——明显影射他自己，顿时暴怒。他纠集二百多名书生冲入春色书坊，要焚烧沈浪的书。在走狗汪世明的带领下，他们找到"风月无边"的书捆并当众焚烧。然而沈浪早已设下圈套：这批书的包装经火烤后，"风月无边"的字样消失，显现出"新政诏书"四字。邓先哭喊众书生焚烧的是国君颁布的新政诏书，这是对抗新政、意图谋反的大罪。沈浪适时现身，逼迫书生们检举主谋祝文华。

兰山城主李芳出面调停。沈浪向祝兰亭子爵开出条件：一、祝兰亭当众掌掴儿子祝文华；二、祝文华亲手烧掉自己所有存书。祝兰亭为保家族前途，被迫答应。祝文华被父亲打得口鼻出血，又亲手焚毁了自己五千多本心血之作，尊严尽失，从此与沈浪结下死仇。

与此同时，沈浪的书在玄武城上市，同样引发抢购狂潮。书中女主角西门纤纤及其父西门庆，明眼人一看便知影射的是徐芊芊和徐光允。徐芊芊苦心经营八年的才女名声瞬间崩塌，未婚夫张晋得知后怒不可遏，冲到徐家打了徐芊芊一耳光。张翀太守却冷静地劝儿子不要被愤怒冲昏头脑，目标应该是整个玄武伯爵府而非沈浪一人。

张晋与徐芊芊的订婚宴上，各方势力集结，准备围攻沈浪和玄武伯爵府。第一波攻击：徐家管家花钱雇了一个下等娼妇，当众声称沈浪嫖妓不给钱。沈浪反手给了她十个金币，然后招来二十几个乞丐"享用"她——既然收了钱就要服务到位。娼妇吓得当场招供出徐管家。沈浪迫使张晋下令打断徐管家的双腿，自己亲自动手将徐管家打成残废。

第二波攻击：主簿王涟拿出一份八年前的考卷，声称沈浪书中"善有善报，恶有恶报"一诗是剽窃他的，考卷上确有这首诗，看似铁证如山。沈浪趁王涟饮酒时用强效致幻剂下毒，王涟在药力作用下将真相和盘托出：诗是沈浪写的，考卷上的字是拼接伪造的，指使者是城主柳无岩。丑态毕露的王涟当众撕开假考卷，剽窃诬陷彻底败露。

第三波攻击：新科进士、银衣巡察使李文正出场，指出沈浪书中有藏头诗"天诛矜君"，认定这是诅咒王族、对抗新政的谋反大罪，要当场锁拿沈浪。沈浪却淡然回应：南殴国主矜君已经谋反了。原来宁萝公主此前曾秘密来伯爵府求医，沈浪诊断出她是铅中毒，下毒者正是其夫矜君。玄武伯爵府早已得到密报，矜君毒杀宁萝公主未遂后被迫提前谋反。沈浪故意在书中埋下这颗雷，就等着敌人来踩。李文正当场崩溃，倒地抽搐口吐白沫。三战全胜，沈浪碾压全场。

王涟清醒后，沈浪用患有脏病的妓女使他染上不治之症。王涟在绝望中自宫，却被沈浪告知毒血早已注入血脉，必死无疑，生不如死。

张翀太守得知沈浪的战绩后极为震撼，竟生出招揽之心，派女儿张春华前往玄武城。张春华以探访金木兰为名来到伯爵府，临走前念了一首藏头诗，暗邀沈浪半夜赴廊桥私会。沈浪识破美人计，主动向木兰坦白，化解了信任危机。

国君下旨：沈浪检举矜君谋反有功，赐太学监生出身——这在当时是极低贱的功名，无异于羞辱。对李文正的处理，国君仅罚俸一年，官职功名全部保留。这意味着新政不仅不会暂缓，反而要加速推进。玄武伯上奏的两道奏折全部落空，国君的态度极为强硬。

李文正觉得自己圣眷在握，立刻变成一条疯狗，诬陷金木兰麾下骑兵纵马践踏平民致死，带兵到伯爵府抓人。然而沈浪早在半个月前就布置了一个惊天阴谋。他让人将苏轼的千古名篇《水调歌头》卖给国都名妓何妧妧，助她在王太后寿辰上大放异彩；又设计华丽性感的衣裙让何妧妧惊艳全场，引起国君宁元宪的垂涎。国君临幸何妧妧后发现她并非处子，心生不快。此时沈浪又让人在李文正的住处"搜出"何妧妧的画像和一条带落红的丝帕，制造了李文正与何妧妧有私情的假象。国君勃然大怒，不顾刚刚发下的旨意，派出黑水台高手将李文正凌迟处死。李文正至死都不知道自己是怎么被算计的。

沈浪以翻手为云覆手为雨的手段，远在千里之外就决定了李文正的死局。玄武伯爵府与国君、张翀之间的博弈，进入了更加激烈的新阶段。
