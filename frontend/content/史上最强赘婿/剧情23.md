# 剧情23

**女王城之战：** 罗素公爵率大军兵临女王城下，城主霍尔公爵以维达族混血之身宁死不降，坦然受死。罗素公爵正欲斩下其头颅之际，美杜莎女王裂土而出，带来满城冰霜寒气。她以颠倒众生的魔幻魅力登场，赤足而行，所过之处万众跪伏。她率领四大高手轻松撕开罗素公爵的防线，三剑将对方大剑震成碎片，击败罗素公爵后将其轻飘飘掷出城外，迫使其退兵二十万。沈浪亲眼见证，震撼于美杜莎女王已从猛将涅槃为充满魔幻魅力的王者——她走到哪里，哪里的战斗就结束。

**沈浪身份确认：** 美杜莎女王称沈浪为"我孩子的父亲"。沈浪从她口中确认自己正是姜离之子，也是仇妖儿一直等待的"弟弟兼主君"。张春华得知这一真相后震惊不已，一时难以接受心上人从"才华横溢的流氓"变成了天下共主。她需要时间消化这个事实。

**美杜莎女王的真相：** 美杜莎女王坦言，她体内只有10%的仇妖儿意识。她强大的上古人类灵魂需要相应的躯体承载，但仇妖儿的人类身躯远远不够，导致她绝大部分时间只能在地下沉睡。她只剩一年的寿命，临死前会将完整的仇妖儿还给沈浪。幺幺也面临同样问题——她太过优秀聪明，普通人类躯体支撑不了她的灵魂，每天只能苏醒一刻钟，生机不断凋零。美杜莎女王将姜离留下的宝箱交给沈浪，宝箱需用圆周率密码开启，内有五瓶丹药、五卷上古典籍和几十万字的珍贵资料，记载了西方世界如石油矿、金矿、上古遗迹、亚马逊部落机密等核心情报。姜离游历新大陆数十年的发现全部在箱子中。

**海伦公主之谜：** 美杜莎女王推测，女王城的真正继承人海伦公主很可能是姜离与雪莱女亲王之女，即沈浪同父异母的姐姐。四十年前姜离曾秘密到过女王城，在王宫陵墓留下大量痕迹。海伦公主身负东西方混血，若她能成为西仑第三帝国女皇，将成为沈浪最强大的盟友。可惜她十六岁便离开女王城冒险，已失踪十七年。美杜莎女王还告知沈浪，亚马逊部落与姜离也有隐秘联系，姜离曾潜入过亚马逊并留下关于金字塔命运的预言。

**告别与出征：** 沈浪在最后一晚陪女儿幺幺，给她做了特制魔方——六面分别是爸爸、妈妈、幺幺和三个弟弟妹妹的画像。幺幺半分钟就拼好了，聪明得让沈浪惊叹。沈浪依依不舍送女儿入睡，发誓一年内必定归来。美杜莎女王告知沈浪，只要她活着就能牵制狄波丝公爵和西仑王朝百万大军，这是沈浪发展的黄金窗口。沈浪带着两千精锐乘船离开女王城——五百被亚马逊流放的罗兰骑士团、一千黑珍珠海盗团、五百姜离旧部东方骑士团，还有张春华和她的学徒。兰风将军率东方骑士团跪拜高呼"陛下万岁"，张春华也无奈跟着跪下。沈浪的西方大业正式起步。

**木兰城奇迹：** 沈浪在碧潮半岛建立基地，用火山岛的火山灰制造水泥，以砖头烧制快速建造房子。仅一个半月就建成了规模可观的城镇，令周围海盗叹为观止，称他为"魔术师"。沈浪打开姜离箱子后获得大量珍贵资料，发现了石油矿、金矿位置和亚马逊部落的核心机密。他购买八千圈养奴隶赐予自由民身份，总人口扩至一万三千。为筹措资金，沈浪烧制出精美瓷器，以独家销售权与女富商希尔换取了25万金币。但好景不长，狄波丝公爵得知沈浪竟在碧潮半岛筑城，下令全面贸易封锁。

**海上封锁与索伦大帝：** 血腥男爵翻脸为敌，彻底封锁木兰城海域，任何海船靠近都会被击沉。此时狄波丝公爵已成为西仑帝国南方守护，麾下军队超过十万，海陆皆强。与此同时，索伦大帝——拥有黄金斗气、刚从极北大陆冒险归来的绝世强者——正一人一剑南下征服城邦，顺者昌逆者亡，已收服三十九座城邦。其声势之盛堪比当年的西仑大帝。狄波丝公爵全力支持索伦，期待借助他的力量让鲁索家族涅槃成为帝国亲王。美杜莎女王则是索伦最后的征服目标：要么成为皇后，要么死。沈浪的时间变得极为紧迫。

**木兰的魔鬼大三角：** 回到半年前，金木兰率舰队进入地狱般的魔鬼大三角。这里有毁灭性的闪电、密布的暗礁和诡异的飓风。木兰凭借上古人类的感知力，一次次避开致命危险。她耗尽精神力后靠药物强行透支，坚持四天四夜，在即将崩溃的最后一刻带领全船冲出黑暗，来到如梦如幻的海上城市。随即被无数海怪包围，危急关头神秘女子海伦出现解围——她自称是姜离的女儿。

**研制炸药与火炮：** 沈浪利用硝石岛取之不尽的硝石和火山岛的天然硫酸池，成功制造出TNT炸药，一包就能炸毁一栋房子。但火炮实验发生意外，生铁炮管承受不住TNT当场炸膛，一名炮手牺牲。改用黑火药后成功试射，但准度极差。受限于铁匠水平，到开战时仅造出六门堪用的火炮。

**男扮女装潜入亚马逊：** 距狄波丝大军来袭仅一个半月，沈浪男扮女装化名"隆娜娜"潜入亚马逊女王国度。亚马逊部落是与世隔绝的强大战士国度，但三分之一的女战士受痛风诅咒折磨，严重者瘫痪后只能自杀。沈浪用秋水仙碱和原始青霉素药到病除，治好了上千名女战士，还通过手术治好了埃达女王的不孕不育症，使黄金血脉得以传承。沈浪甚至在亚马逊岛上学会了女战士日常的可怕训练方式——她们每天在海底屏息练剑十分钟以上。

**大预言与火刑：** 大祭师识破沈浪男儿身，沈浪主动承认。他预言亚马逊将遭遇灭顶之灾，被绑在刑架上处以火刑。最后一刻，北方噩梦火山喷发引发惊天地震，五个小金字塔接连爆炸灰飞烟灭。沈浪在烈焰中被多拉公主舍命救下。大祭师被揭露是叛徒——因当年生下男婴被夺走而怀恨勾结外敌，但埃达女王告知她儿子其实没死，而是被秘密送养。大祭师悲痛之下欲自杀被阻止。

**拯救金字塔：** 埃达女王带沈浪进入金字塔地下五百米核心区域，一个装有金属氢的巨大圆球已进入自毁倒计时。沈浪凭借智脑中存储的上古噩梦石知识，在最后五秒内完成五百多个精密步骤，中断了自毁程序。埃达女王被沈浪的智慧和胆识深深折服，以"放逐"之名将八千亚马逊女战士交给沈浪。这支拥有上古血脉的军队是西方世界最强大的战士。

**木兰城防御战：** 奥斯丁伯爵率五万大军从陆地进攻。火神教的火药包投石机和火箭车因准度太差收效甚微，战果为零。张春华在山谷城关地下埋设大量炸药，一波惊天爆炸将地面掀开，一万攻城敌军粉身碎骨。奥斯丁伯爵不愧沙场老将，迅速使用投石机火力压制，使守军无法投掷手雷，随后一万大军冲锋夺下春华关。九万敌军包围木兰城，城内守军仅剩一千四百人，炸药几乎用尽。面对着黑压压无边无际的敌军，兰风将军率众高呼"誓死保卫皇后城"，张春华身着华丽裙衫守在埋满炸药的城主府内，准备城破时引爆同归于尽。

**八千铁骑救城：** 最危急关头，沈浪率八千亚马逊战士从北边赶到。春华关两千守军被亚马逊战士以惊人弹跳力直接跃上五米城墙，几分钟内全歼，无人逃脱。七千二百名亚马逊骑兵骑着巨型战马冲入敌军四万步兵方阵，以摧枯拉朽之势碾压屠杀，所过之处皆成肉泥。敌军防线如同纸糊一般被撕碎，战场上血流成河。杜克伯爵率四千骑兵断后，在决斗中被多拉公主斩于马下。奥斯丁伯爵仅带少数人逃回碧金城。整场战役中，狄波丝公爵的十万大军几乎全军覆没。木兰城以两千守军之力，靠炸药和亚马逊军团援军，大获全胜。沈浪从西方世界流亡者一跃成为拥有强大军团的实力派，他的事业从此有了坚实的根基，也与狄波丝公爵结下了不死不休的血仇。
