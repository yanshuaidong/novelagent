# 应天府篇

> **篇章时间**：天启元年（1621）二月至入学后  
> **篇章地点**：南下旅途 → 应天府（金陵） → **上元县**（府治所在县，秦淮一带） → 弘文馆  
> **主角状态**：信王朱由检，化名**朱衡**，十岁  
> **修仙体系**：见 `武力体系.md`

---

## 故事一 · 南下旅途

### 人物

| 类型 | 角色 | 性格 / 言行 / 作用 |
|------|------|-------------------|
| 主要 | **朱由检（朱衡）** | 化名富家少爷南下；目睹民生凋敝后确立目标——**修身**，"手里没刀说什么都空"；以观察与自省推动后续修炼决心 |
| 主要 | **王承恩** | 结丹后期护卫，沉默可靠；负责旅途安保，是主角与外界冲突时的实力后盾 |
| 次要 | 漕船纤夫、扬州盐商（群像） | 纤夫苦、盐商奢，构成"天下烂得不均匀"的对照；无姓名，以见闻烘托主角认知 |

### 情节

| 阶段 | 内容 |
|------|------|
| **开端** | 信王离京后，陆路至通州，漕船入运河，渡长江，经镇江、龙潭驿，向应天进发 |
| **发展** | 沿途见闻：运河纤夫卖苦力、扬州盐商挥金如土；主角以历史系学生的眼光审视明末社会剖面 |
| **高潮** | 贫富悬殊的冲击与南下弘文馆修仙的使命叠加，主角内心确立当下第一目标——先把身子练上去 |
| **结局** | 车队抵龙潭驿，旅途段落下；修身之志成为后文修炼、破案、入学的内在动力 |

### 环境

| 类型 | 内容 |
|------|------|
| **自然环境** | 天启元年早春，陆路转漕运再渡长江；运河、长江水道，旅途漫长 |
| **社会环境** | 明末漕运体系下纤夫阶层困苦；扬州盐商奢靡，社会财富分配极不均；弘文馆修仙是主角此行的制度性目标 |

## 故事二 · 龙潭驿 · 收双儿

### 人物

| 类型 | 角色 | 性格 / 言行 / 作用 |
|------|------|-------------------|
| 主要 | **朱由检** | 出资葬父、赠银还自由；不施恩而图报，以"期满还自由"立规矩；言行体现"有恩必报、用人有道" |
| 主要 | **双儿** | 十五六岁，眼尖、知进退；拒银而请跟随——"恶霸必再来，孤身拿银走不出三十里"；认准恩公是好人，以三年之约换安全感 |
| 主要 | **王承恩** | 出手打趴泼皮，实力立威；为主角行善扫清障碍 |
| 次要 | **李姓胖子** | 龙潭驿地头蛇，逼迫卖身葬父的女孩；被王承恩打趴，衬托主角团实力 |
| 次要 | 双儿亡父 | 卖身葬父的由头；安葬后双儿无牵挂，随队入城 |

### 情节

| 阶段 | 内容 |
|------|------|
| **开端** | 龙潭驿门口，双儿卖身葬父，遭李姓胖子逼迫 |
| **发展** | 王承恩出手制伏泼皮；朱由检出资葬父并赠银子，许其自谋出路 |
| **高潮** | 双儿拒银，陈述独行必遭劫、恶霸必再来的现实，请求跟随；主角允三年之期，期满还自由，改呼"公子" |
| **结局** | 父亲安葬毕，双儿入队；车队继续南下，进入应天城 |

### 环境

| 类型 | 内容 |
|------|------|
| **自然环境** | 龙潭驿，南下入应天前的驿站；旅途末段，人困马乏 |
| **社会环境** | 卖身葬父的民间惨状；驿站地痞横行、弱肉强食；主角以富家公子身份行善，尚未暴露信王身份 |

## 故事三 · 入城初日 · 上元县酒楼

### 人物

| 类型 | 角色 | 性格 / 言行 / 作用 |
|------|------|-------------------|
| 主要 | **朱由检** | 富家公子姿态但不摆架子；拦下包间要求，"大堂就好，热闹"；一边吃一边给双儿讲菜，逗她直流口水 |
| 主要 | **双儿** | 初进城，肚子咕咕叫；眼尖发现靠窗空位，拉众人入座；天真反应带出温馨日常 |
| 次要 | **王承恩** | 习惯要包间，被主角拦下；护卫身份与公子做派形成反差 |
| 次要 | 酒楼老板、伙计 | 强调包间需预定；上应天特色菜，营造地方风物 |

### 情节

| 阶段 | 内容 |
|------|------|
| **开端** | 入应天城初日，双儿饥肠辘辘，朱由检带往上元县秦淮河一带最好的酒楼 |
| **发展** | 王承恩要包间被拒；主角无所谓，坐大堂；双儿发现靠窗位子，众人落座 |
| **高潮** | 上菜，主角绘声绘色讲盐水鸭、什锦菜、鸭血粉丝、桂花糖芋苗等，双儿听得直流口水——轻松温馨的"哥哥带妹妹吃饭"时刻 |
| **结局** | 日常段落收束；同一酒楼、同一顿饭，将无缝接入下一故事「公堂疑案」的冲突（与周云朗一拨人同桌场） |

### 环境

| 类型 | 内容 |
|------|------|
| **自然环境** | 天启元年二月，应天入城初日；上元县秦淮河一带，酒楼临河（可虚构名如「秦淮春」「金陵楼」） |
| **社会环境** | 应天府为府级，府尹掌府事；城内刑名断案在**县衙**，秦淮酒楼属**上元县**境；富家公子下馆子、大堂吃饭是寻常市井景象；节奏故意轻松，与后续公堂疑案形成反差 |

## 故事四 · 公堂疑案

### 人物

| 类型 | 角色 | 性格 / 言行 / 作用 |
|------|------|-------------------|
| 主要 | **朱由检** | 十岁少年，观察力破案：当庭提三疑点（衣着尺码、漕工体格、死后心跳）；气不过草菅人命，以逻辑链戳穿设局 |
| 主要 | **周云朗** | 周家嫡子，与曹铁柱理论、混乱中对方倒地；被孙旺一口咬定失手杀人，成为陷害靶心 |
| 主要 | **周云熙** | 闻讯赶至县衙公堂；欲谢主角，以弘文馆外院入门资格还人情；后于河边被主角思想支持，暗生情愫 |
| 主要 | **周继宗** | 周家旁支，反派；雇曹、孙设局，提前给曹服强刺激性药物；与县令勾结，欲瓜分家产并觊觎表妹 |
| 次要 | **赵广平** | 上元县县令，与继宗勾结；草草定罪，把锅推给死者 |
| 次要 | **曹铁柱** | 漕工，身强体健；被下强药后剧烈运动致心源性猝死，成为局中棋子 |
| 次要 | **孙旺** | 曹同伙，挑衅后奔县衙鸣鼓报官，堂上作证咬定云朗 |
| 次要 | **钱福** | 替继宗送五十两银子的中间人；官府追查前被灭口，线索中断 |
| 次要 | **周父** | 上元县富商，保守；宴请致谢时哭诉没教好儿女，暗示女儿抛头露面、读女学"不守妇道"——云熙跑出 |

### 情节

| 阶段 | 内容 |
|------|------|
| **开端** | 故事三同一酒楼：周云朗一拨与主角团同场；曹铁柱挑衅云朗，混乱中曹倒地气绝，孙旺奔**上元县衙**鸣鼓报官 |
| **发展** | 云熙赶到公堂；孙旺作证、主角如实陈述云朗未下死手；周继宗现身公堂——实为设局；赵广平与继宗勾结，量刑极重 |
| **高潮** | 主角提三疑点：曹衣着尺码不合、漕工壮汉无磕碰却暴毙、死后一个时辰仍有心跳（强心药致心源性猝死）；捕快搜出曹家五十两银子，钱福被灭口线索中断 |
| **结局（公堂）** | 经查确为陷害；草包县令与继宗推责死者，孙旺伪证被草草遮掩 |
| **尾声** | 云熙以弘文馆入门资格谢主角；云朗请吃饭，周父出席责难女儿；主角追至河边，反"存天理灭人欲"专对女子，举古文反例，主张女子亦可成事——云熙顿生好感 |

### 环境

| 类型 | 内容 |
|------|------|
| **自然环境** | 上元县衙公堂、秦淮河酒楼、河边；连续数日，案情自饭桌延至堂审 |
| **社会环境** | 县衙刑名、鸣鼓报官制度；周家富商家族内部嫡庶、旁支争产；弘文馆女学与传统"妇道"冲突；副院长愿埋没天才云熙 vs 周父保守；主角破案靠观察力，情感线支持女性事业但不激进说教 |

## 故事五 · 入学与开学大典

### 人物

| 类型 | 角色 | 性格 / 言行 / 作用 |
|------|------|-------------------|
| 主要 | **朱由检（朱衡）** | 自称京城富家少爷，未表信王身份；将皇兄所赐**信王甲班请柬**转赠双儿，自用云熙外院推荐入**癸班**学号 48；测出**九天灵根**后立即决定只公开金灵根，藏拙避疑 |
| 主要 | **双儿** | 入学前夜获赠信王甲班请柬，感激涕零；持帖入**甲班**；变异冰灵根、光强之极，全校轰动，反衬主角被忽视 |
| 主要 | **周云朗** | 与男主同班癸班；真灵根（双属性）、光强而纯，压过继宗，获黄先生赞叹 |
| 主要 | **周继宗** | 癸班反派同班；测前嘲讽免试纨绔与"公堂凶手"；真灵根中等，测后被连番打脸，脸抽搐哑口 |
| 主要 | **沈砚秋（沈铁面）** | 癸班掌班教习；厌引荐入学，认定免试生多是纨绔；见朱衡天灵根后态度 180° 转变，当众力赞 |
| 次要 | **周云熙** | 内院天灵根，博闻强记；已推荐主角入学，本段不在测试焦点 |
| 次要 | 同班某同学 | 真灵根但光弱而杂（三属性），展示同档灵根强弱之差 |
| 次要 | 乙班某男生 | 教导老师之子，真灵根中已透变异灵根的光，全班轰动 |
| 次要 | 弘文馆校长 | 开学典礼引张载**横渠四句**，定馆训使命 |

### 情节

| 阶段 | 内容 |
|------|------|
| **前夜** | 正月三十夜，入学前最后一晚：朱由检将皇兄离京所赐**信王甲班请柬**转赠双儿，嘱其入学读书修炼；双儿自知不识字、本只愿一辈子伺候，感激涕零，郑重收下；朱由检自用云熙外院推荐帖入癸班，藏拙避疑 |
| **开端** | 二月初一，弘文馆开学；今年 500 新生分甲乙丙丁戊己庚辛壬癸十班，癸班又称"走后门班" |
| **发展** | 入学安排：朱衡、云朗、继宗同班癸班；双儿甲班；沈砚秋掌癸班风纪。开学典礼，校长强调横渠四句 |
| **高潮** | 灵根测试（详见 `武力体系.md`）：十班**同时**开测；癸班依序测周继宗、周云朗，末位朱由检；朱由检测试中途穿插甲班双儿——双儿变异冰灵根、惊呼轰动，**盖住**朱由检九天灵根余下八色（九天灵根，穿越者体质）；癸班遭忽视、继宗真灵根嘲讽反成笑话；沈砚秋近台目睹天灵根后当众力赞 |
| **结局** | 主角决意只公开一色天灵根、隐藏九天灵根；继宗同班伏笔已埋，为后续冲突留空间 |

#### 灵根测试明细（高潮展开）

**十班同时开测**，各校场侧畔各置测试石，掌班依序叫号；朱由检视角紧绑癸班，甲班双儿段落**穿插**进行。

1. **周继宗**（癸班首位）：真灵根（双属性），光强中等 → 测完即嘲讽朱衡、云朗  
2. **周云朗**（癸班次位）：真灵根（双属性），光强而纯，**光强于继宗**；黄先生：「比云熙那天灵根差远了」  
3. **同班某同学**（癸班）：真灵根（三属性），光弱而杂  
4. **乙班某男生**（并行）：真灵根已透变异灵根的光（双属性中掺杂一丝变异属性），乙班骚动  
5. **朱由检**（癸班末位）与 **双儿**（甲班，**同时穿插**）：
   - 朱由检按石，金色天灵根、光强之极——癸班近处有人低呼，远场尚未留意
   - 测试石在他手下快速闪烁：金→青→蓝→赤→黄→青白→紫→白→黑→金，九色循环一轮，速度极快——但此时**同一时刻**甲班双儿按石，变异冰灵根亮起，白光纯粹、光强之极；黄先生估**五成概率成结丹**
   - 双儿惊呼、全场涌向甲班——**声浪盖住**朱由检测试石九色循环；除近台教习外无人看清那九色连闪 → **九天灵根**（九色各为一天灵根，丹田气海中九道灵气各不相扰；外人只见一色）→ 决意只公开金灵根、借势藏拙  
6. **沈砚秋**：测前轻视 → 近台目睹天灵根后态度急转，当众力赞  

### 环境

| 类型 | 内容 |
|------|------|
| **自然环境** | 天启元年二月初一，弘文馆操场；应天府弘文馆，太祖所创、仙道一科闻名 |
| **社会环境** | 班级按考试成绩排列，癸班为引荐入学；女学甲班与癸班"后门班"的等级差异；灵根测试公开、全校围观，决定资源与期待；横渠四句定弘文馆使命；九天灵根"前无古人"却须藏拙，因信王身份与穿越者体质不宜张扬 |
