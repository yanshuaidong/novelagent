# 应天府篇

> **时间**：天启元年（1621）二月至入学后  
> **地点**：南下旅途 → 应天府（金陵，府级） → **上元县**（府治所在县，秦淮一带） → 弘文馆  
> **主角状态**：信王朱由检，化名**朱衡**，十岁
---

## 故事情节

### 南下旅途

**路线**：陆路至通州 → 漕船入运河 → 渡长江 → 镇江 → 龙潭驿 → 应天（金陵）

**旅途见闻**
- 运河纤夫苦、扬州盐商奢，"天下烂得不均匀"。
- 主角确立当下目标：**修身**——先把身子练上去，手里没刀说什么都空。

### 龙潭驿 · 收双儿

- 驿站门口，十五六岁女孩**双儿**卖身葬父，遭地头蛇李姓胖子逼迫。
- 王承恩出手打趴泼皮；朱由检出资葬父，赠银子让双儿自谋出路。
- 双儿拒银，请求跟随：恶霸必再来，孤身拿银走不出三十里；认准恩公是好人。
- 约定：跟随三年，期满还自由之身；称呼改"公子"。
- 双儿父亲安葬后，车队入**应天城**。

### 入城初日 · 上元县

**场景**：上元县秦淮河一带最好的酒楼（可虚构名，如「秦淮春」「金陵楼」等）

> **行政说明**：应天府为府级，掌府事者为**府尹**；城内日常刑名断案在**县衙**。应天城郭分属**上元**、**江宁**二县，秦淮酒楼、周家宅邸皆在上元县境内，公堂疑案赴**上元县衙**。

- 双儿肚子咕咕叫，朱由检带她去最好的酒楼吃饭。
- 王承恩要包间，老板说需预定，不预定的没有；朱由检拦下，无所谓，大堂就好，热闹。
- 双儿眼尖，发现靠窗位子空出，拉众人过去。
- 上菜，朱由检一边吃一边给双儿讲将要吃的菜，说如何鲜美，逗她直流口水。
- 可虚构应天特色菜：盐水鸭、什锦菜、鸭血粉丝、桂花糖芋苗等。

**节奏**：主角尚未暴露身份，以富家公子姿态行事；轻松日常，与后续公堂疑案形成反差。

### 公堂疑案

**场景**：上元县衙（应天府下辖县）

#### 案情经过

1. **酒楼冲突**  
   主角团吃饭时，周云朗一拨人也在吃饭。周继宗雇来的曹铁柱、孙旺也在场。曹铁柱挑衅周云朗，云朗与之理论，混乱中曹铁柱倒地气绝；孙旺当即奔**上元县衙**报官，一口咬定云朗失手杀人。

2. **鸣鼓升堂**  
   孙旺赴**上元县衙**鸣鼓报官。周云熙闻讯赶到县衙公堂。孙旺堂上作证，指认云朗行凶。主角如实作答：云朗并未下死手。周继宗也来公堂——实则雇曹、孙设局，瓜分家产并觊觎表妹。

3. **草菅人命**  
   赵广平与周继宗勾结，宣布云朗失手打死人，量刑极重。主角发现疑点，气不过。

4. **设局真相**  
   周继宗提前给曹铁柱服强刺激性药物，剧烈运动导致心源性猝死；曹负责挑衅，孙负责报官作证。

5. **主角提出三疑点**  
   - 曹铁柱衣着为平常料子、尺码不合，不像常去高档酒楼之人，今日突然出现，可疑。  
   - 曹双手、肩上老茧，腹肌分明，双臂双腿肌肉雄厚，应是漕工；如此壮汉无磕碰，扭打中暴毙，不合常理。  
   - 曹已死一个时辰，俯身细听仍有心跳——说明生前服大量强心药物；强药加肢体冲突导致心源性猝死。

6. **搜证与断线**  
   捕快在曹铁柱家中搜出五十两银子。刚要顺藤摸瓜，送银的钱福出事了——被灭口，线索中断。

7. **结案**  
   经查确为陷害。草包县令赵广平与周继宗勾结，把罪名全推给死者曹铁柱，孙旺伪证亦被草草遮掩。

#### 案后情节

- 周云熙要谢主角；主角说：告诉我姑娘名字就好。
- 云熙不想欠人情，给了一个**弘文馆外院入门资格**（内院学生有资格推荐一人，不用考试）。
- 主角与周云朗一同入学（云朗是新生，男主亦然）。男主自称京城来的富家少爷**朱衡**，未表明信王身份。
- 云朗请主角团吃饭致谢；周父出席。
- 周父哭诉：没教好儿女；暗示女儿抛头露面、听信弘文馆副院长谣言、加入女学、不守妇道（未明说，只是暗示）。  
  → 云熙博闻强记、过目不忘，是天才；副院长不愿其被埋没。
- 云熙端酒到门口，听见父亲责难，跑出。
- 主角追到河边，支持女主：叹"存天理灭人欲"专对女子；女子也可干一番事业；举古文反例；封建礼教运行千年，改变须徐徐图之。
- 云熙顿生好感，对主角暗生情愫。

**要点**：朱由检破案靠观察力；情感线支持女性事业，区别于时代，但不激进说教。

### 入学与开学大典

**时间**：二月初一  
**地点**：弘文馆操场

#### 入学安排

- 今年共 **500 名新生**，分 **10 个班**：甲、乙、丙、丁、戊、己、庚、辛、壬、癸。
- 班级按入学考试成绩排列；**癸班**又叫"走后门班"，多为引荐入学。
- **朱衡（朱由检）**：周云熙给的入门资格，**不用考试**，分在**癸班**，学号 48；与周云朗同班。
- **周云朗**：新生，与男主同班。
- **周继宗**：也在癸班，与主角、云朗同班（反派同班）；测前瞧不起朱衡（免试纨绔）、云朗（公堂"凶手"），自诩旁支天才。
- **双儿**：用信王入门请柬，分在**甲班**（比主角大几岁，可入学）。
- **癸班掌班教习** **沈砚秋**（沈铁面）：掌癸班功课风纪；厌引荐入学，认定免试生多是富家纨绔、癸班吊车尾。

#### 开学典礼

- 校长强调使命：朱元璋引用张载**横渠四句**——为天地立心，为生民立命，为往圣继绝学，为万世开太平。

#### 武道天赋测试

测试方式：双手放到测试石上，测试石会发不同颜色的光。

**天赋色（品质）**：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀（六档，越高越强，与灵魂绑定，决定未来品级上限）

**品级与稀有度**（全书武力金字塔）：一品—三品百里挑一，四品—六品千里挑一，七品—九品万里挑一，九品上为凡人悟道天花板，大宗师为塔尖半神。弘文馆测试主要预测四品至九品潜力；天赋色定大档，光强光弱定同档内的潜力高低（如青铜大概率四品；光强者上浮，光弱者下浮）；星耀基本预定未来九品。

**同档辨强弱**：测试石辨**主色**定天赋色；**同一颜色，光越强、越纯、越亮，天赋越高；光越弱、越暗、越杂，天赋越低**。不设子等级，比较时直说即可——「同是铂金，云朗光强，某同学光弱。」若光中透更高一阶的颜色，说明已摸上下一阶门槛，仍按主色定档，不作另立名目。

| 天赋色 | 大致预期品级 |
|--------|-------------|
| 青铜 | 四品 |
| 白银 | 四品上～五品 |
| 黄金 | 五品 |
| 铂金 | 五品～六品 |
| 钻石 | 七品～八品 |
| 星耀 | 九品 |

**近十年星耀色（内院）**：仅 3 人——周云熙、秦良玉、徐云苍。

#### 测试顺序与结果

1. **周继宗**：**铂金色**，光强中等 → 测完即嘲讽朱衡、云朗："免试进来的能有什么天赋。"
2. **周云朗**：**铂金色**，光强而纯，透亮无杂质，**光强于继宗**。黄先生赞叹：「周家子弟还行，只是比云熙那星耀差远了。」继宗脸色难看，嘴硬不服。
3. **同班某同学**（需起名）：**铂金色**，光弱而杂，光泽暗淡，掺杂黄金色、青铜色杂色（约 7:2:1）——同等铂金，光强光弱差一截。
4. **乙班某男生**（教导老师之子）：**铂金色**，光强至极，已透钻石光（钻石五成、铂金四成、黄金一成），全班轰动。
5. **双儿**（甲班，先测）：**钻石色**，光强之极，纯澈无杂！全校轰动；老师估约**五成概率成八品**——八品属万里挑一，概率之低令全场沸腾。**无人注意到癸班的主角。**
6. **朱由检（最后）**  
   - 第一次：**星耀色**，光强之极 → 全场看甲班双儿，忽略癸班。  
   - 颜色暗淡后，天赋石再亮，二次启动，第二次检测：**又是星耀色，光强之极**。
   - **双完美星耀**（两次星耀、光皆至极，穿越者体质，前无古人后无来者）。  
   - 双星耀意味着丹田两色交融、修炼互不干扰；外人探查无法分辨，只见一色，仅主角自知两色。  
   - 主角立刻决定：**只公开一色星耀，隐藏双完美星耀**（避免被怀疑）。  
   - **周继宗**脸抽搐、哑口无言——铂金嘲讽星耀，自取其辱。
7. **沈砚秋（掌班教习）**：测前看不起癸班免试生；见朱衡觉醒星耀且光强之极，态度180度转变，当众力赞。

## 爽点

1. **龙潭驿收双儿**  
   王承恩出手教训泼皮；主角出资葬父、赠银还自由，双儿知恩图报主动跟随——初显主角"有恩必报、用人有道"的气度。

2. **酒楼日常**  
   富家公子不带架子，大堂吃饭、给双儿讲菜——轻松温馨，与后面公堂疑案形成强烈反差。

3. **公堂破案**  
   十岁少年当庭提出三疑点，靠观察力戳穿设局：衣着尺码、漕工体格、死后心跳——逻辑链清晰，打脸草包县令与反派表哥，爽在"智取"而非武力。

4. **河边支持云熙**  
   反"存天理灭人欲"专对女子，举古文反例，主张女子亦可成事——思想超前但不说教，情感线自然起步。

5. **天赋测试反转**  
   全场轰动双儿钻石色，无人注意癸班；主角最后测出**双完美星耀**——"全场以为她是天才，主角才是真正的天花板"。

6. **周继宗天赋打脸**  
   测前嘲讽朱衡、云朗；自己铂金便翘尾巴 → 云朗光强于己、朱衡星耀，连番哑口——爽在反派前期嚣张、后期自扇耳光。

7. **沈砚秋态度急转**  
   掌班教习测前轻视癸班免试生，见朱衡星耀觉醒后当众力赞——爽在"最看不起你的人，不得不低头"。

8. **低调藏拙**  
   主角立刻决定只公开一色星耀，隐藏双星耀——符合"不想暴露穿越/皇子"的策略，留后续冲突与成长空间。

9. **反派同班**  
   周继宗与主角、云朗同班（癸班），入学后冲突伏笔已埋。
