# 熹宗实录故事摘要（续）

> 据《明熹宗悊皇帝实录》第十九至第三十册（卷之三十六至六十三），时间跨度约自**天启三年七月**（1623）至**天启五年九月**（1625）。

---

## 一、边饷枯竭与关内外军心不稳

此段最突出的背景，是辽事五年、加派新饷仍不敷用，关内外军士缺饷、逃兵、鼓噪接连不断。

- **兵部清饷清兵**：吴甡等疏请清查山海关及蓟密、永昌、通州新旧兵额与虚冒；旨令振武营速核，各边通查索饷、勒限确报。
- **方有度算账**：山海一关年耗约四百万两，各处新兵又约百二十万，加派四百八十五万仍缺一百六十二万；请户兵二部总会计、简兵就饷。
- **蒋允仪、潘云翼**：关门月饷亏缺，士卒露宿营房倾圮；袁崇焕称括尽关上始凑五月之饷。潘云翼论关抚更迭与枢辅用人，上命粮饷九卿会议、勿妄猜议辅臣。
- **孙承宗**：榆关内外城垣房屋因霪潦坍圮引灾求罢，温旨慰留；后屡请月饷，户部稽延，旨令将抚按并入考成。
- **董汉儒奏**：延绥、宣府、宁夏等路逃兵投夷，关上月饷户部不转，本色虽有不按时给发；请悬严令擒逃必斩、饷须刻发。
- **户部发帑**：七月发内帑十万充关饷；八月再发十万；九月又准十万。王象乾请抚赏，出帑五万、太仆马价十万。
- **解学龙、陆文献**：论关门米价腾贵、海运陆运、运草、简兵练辽民、方田抗骑等，旨酌行。

## 二、工部冬衣案与钟羽正去位

七月间爆发**冬衣铺盖银**争端，成为宫府冲突标志性事件。

| 环节 | 内容 |
|------|------|
| 起因 | 内官数百成群至工部逼取冬衣；岁例增至十三万一千四百余两，工部借四司料银，外库亦匮 |
| 杨所修、成明枢 | 斥中官毁部体、收净身男子非五年之例；司空钟羽正曾受辱于诸宦 |
| 钟羽正 | 屡乞休，称十三万一时难办，陵工军饷皆告乏；请分秋冬二次解进 |
| 周士朴 | 言辱部臣即辱朝廷，羽正志决，恐中涓以一冬衣逐一部堂 |
| 结果 | 七月丁未准羽正回籍调理；王舜鼎继工部 |

## 三、《光宗实录》告成与恩赏

- **七月乙亥**：《光宗贞皇帝实录宝训》成，叶向高等进呈；后拟御制序二篇、行进呈仪注。
- **七月甲辰**：监修张惟贤等进实录宝训，上御皇极门受之，百官朝贺。
- **恩赏**：张惟贤加太保，叶向高加特进光禄大夫上柱国（后改左柱国），韩爌、何宗彦、史继偕、孙承宗、朱国祯等俱加恩荫子；八月史继偕许致仕，加少保。
- **九月**：以实录成再赐辅臣银币、麒麟服等；十月又赐银币。

## 四、京营、京师盗案与班军之弊

- **京营操兵鼓噪**：成铎、柴登为首，枭示以肃纪律。
- **彭汝楠等**：班军月粮经手衙门多、解额拖欠、书役包揽，致三月无粮；请户兵二部速给，验年貌清册。
- **彭汝楠**：力推飞石、步上达教习；崔拱辰赴任违限八月始到，罚之。
- **彭汝楠（十月）**：条陈捕务省马匹、选番役、重夫哨、严查核、信赏罚、肃夜禁、清捕害，俱依议行。
- **南海子盗案**：近郊大盗纵横，多逃兵、通州营丁；命严缉，盗出该营则参总兵。
- **南京大内左傍宫灾**（七月）。

## 五、辽东与海外：爱塔、毛文龙、关防

- **刘爱塔（刘兴祚）**：登莱袁可立密遣沈有容接应，报七月来归；奴觉后将爱塔及李永芳长子械去，四卫尽空，仅西虏千人。
- **张凤翼（八月）**：出关巡视，陈守关三策——以山海为家、以前屯为家、以毛文龙为前矛；请六万兵、与枢辅商确。
- **孙承宗**：条陈守、款、战三端，请宁远—觉华—广宁步步屯筑，勿弃关外；又论经抚不宜分、饷不可缓。
- **周永春**：以开原失陷论戍。
- **满桂、袁崇焕、马世龙**等将吏任用，孙承宗与言官论人才短长。
- **十月**：毛文龙报金州复、满浦昌城捷，发帑三万劳赏；袁可立、方有度互参奏真伪，上已有旨。

## 六、贵州之役：大捷与惨败

### 七月—八月：擒魁与初胜

- 贵州总督**杨述中**报**何中蔚**就擒，论功升赏。
- **朱燮元**：红崖、天台、白崖、楠木等囤攻克，永宁大半收复；二酋入古蔺结水西，虑粮不接济。
- **侯恂**：陈屯六广、守乌江、清上卫等方略；纠金章等观望违限。
- **八月**：磔何中蔚等，戮佟瑞年、佟守仁于西市。

### 八月—九月：王三善兵败身死

| 阶段 | 事件 |
|------|------|
| 八月 | 王三善议班师，陈守愚诈降；旋进捣大方，奏捷，奢社辉、安位焚巢窜火灼堡 |
| 八月乙丑 | 王三善于**鸭池**兵败，自刎不死，为贼所执遇害；监军岳具仰、方明栋、秦明屏等没 |
| 原因 | 三路进兵（陆广、鸭池、黄沙渡），轻敌急战；独山土官蒙诏卖阵，陆广粮尽大败，鸭池随之溃 |
| 朝议 | 侯恂、胡永顺等论剿抚得失；杨述中被解学龙劾坐视；兵部陈战守善后九事 |
| 后续 | 蔡复一总督贵州；侯恂条陈拯黔六事；九月杨述中再报攻破碗哈等处捷 |

## 七、四川奢乱与湖广协饷

- **张论**（八月）：详陈蜀中逆贼、土司、兵、饷、吏民、蛮民七端形势；奢崇明、安邦彦仅余游魂，请发帑五十万限期剿平。
- **朱燮元**：五路渐入，李惟新等招降擒斩；后奏龙场坝离永宁二百里，疫死、洪水，只得据险固守。
- **湖广—四川兑运**：陈大道查楚蜀饷，已兑八十余万，尚欠近四十万；旨令差官星驰催解，量拨四川十万。
- **九月**：叙贵州、四川诸臣功罪（史永安、李橒、刘锡玄、黄运清等）；朱燮元议蔺地以赤水河为界，河东属黔、河西属蜀。

## 八、红夷（荷兰）犯闽与彭湖

- **周祚**（七月）：红夷据彭湖背约筑城，泉漳增兵造船费饷，请发帑。
- **游凤翔**（八月）：比宋襄阳榷场之鉴，陈互市、鱼船不通、钦依滥设三患；张嘉策闭城不援，请逮问。
- **南居益**（八月）：红夷船愈多，要求互市；请排水兵五千、连营水陆，用本省节省库银。
- **兵部**（九月）：斥红夷狡诈，令设法驱逐，便宜行事。
- **崔其观**：纠程再伊、张嘉策受红夷三万金许澎湖互市。

## 九、内廷恩荫与内操之争

- **七月**：王体乾、魏进忠等十二人准世袭锦衣职；客氏子侯国兴特准世袭。兵部董汉儒、程注、汪泗论等连章谏，朱大典、周之纲等另疏，俱不从。
- **刘之凤、胡良机等**：请罢内操；上谕内操不涉六部钱粮、为拱卫大祀，屡旨已明，再渎重处。
- **客氏**：瑞、惠、桂三王庄田欠课，逮民问罪；吴甡言宜抚按核奏，上责其牵扯，夺俸三月。
- **内使王文进**殴杀戴进忠（八月），庄士元为刘朝、郑养性写揭通赂，论死。

## 十、朝鲜废立与东事外交

- 昭敬王妃**金氏**疏请废**李珲**、立**李倧**。
- 礼部林尧俞等：李珲若有通奴则难逭，李倧若赤心中国则可勘议；旨令部兵差官同毛文龙查明。
- 周朝瑞请慎择朝鲜使臣；袁可立、毕自严、潘云翼等各有条陈。

## 十一、朝局：起废、考选与门户之争

### 起用与点用

- 吏部会推**王纪**为刑部尚书，上责擅自起用奉旨回籍之官，司官罚俸；叶向高疏救，司官免究。
- 会推**李三才**、**冯从吾**为正，上独点**余懋衡**、**曹于汴**为兵部侍郎、左副都御史；二人辞陪推，余懋衡九月引疾归。
- 邹元标推南京吏部，留中；程注等请惜老成。

### 考选、察典与南北台

- **赵南星**升吏部尚书；论偏重进士、北科道、京官之弊。
- **张继孟**：不得北道，罚俸半年；范得志、卢承业、王允成等互劾，为翻察典之争。
- **左光斗**：陈移宫始末，请复杨涟、文震孟、郑鄤等，不许。
- **叶向高**：八疏乞归，上屡温谕；论添注为旧例，请止疑议。

### 言官获谴

- **陈良训**（九月）：疏陈防微四款（圣躬、诏令、谏议、人才），内有“世运将终”语，下镇抚司打问，后罚俸半年。
- **李应昇**（正月条）：论赏罚不明、刘朝虽死而仿效者众，上切责其泛。

## 十六、此段历史脉络（简括）

天启三年夏秋，朝廷一面为**光宗实录**告成、**郊祀**大典忙碌，一面深陷**辽饷**、**黔蜀**、**闽海**三线危机：关外孙承宗力主屯守而饷匮兵逃；贵州王三善先胜后败、殉节鸭池；四川朱燮元屡捷未平；福建红夷踞彭湖要挟互市。京师则**冬衣案**逼走钟羽正，**内宦世袭**引言路交争，**考选南北**与**移宫余波**未歇，**叶向高**屡疏求去而勉留。至十月，**停刑**、**实录恩赏**、**妖寇叙功**并至，而户兵尚书、本兵相继去位，朝政内外交困之局愈见分明。

## 十七、皇子诞生与覃恩大赦

天启三年**十月二十二日**，皇贵妃**范氏**诞育皇子（即日后**怀冲太子**），为登极以来嗣续大事。

| 环节 | 内容 |
|------|------|
| 礼仪 | 祭告南郊、北郊、太庙、社稷；颁恩诏告天下；内帑、太仆、光禄、顺天税契凑赏银四十万两 |
| 推恩 | 新城伯**王昇**进侯；客氏子**王国兴**、**张国纪**等皇亲升秩；范氏弟**范守仁**等晋职 |
| 内阁 | **叶向高**加上柱国兼支尚书俸；**韩爌**左柱国；**孙承宗**、**朱国祯**等加少傅/少保并荫子 |
| 大赦 | 闰十月十六日前罪除十恶、封疆失机等不赦外，蠲免万历以来拖欠税粮、追赃、盐课等条目浩繁 |
| 叶疏 | 请复**文震孟**、**郑鄤**等七谪官，上不准，诏款报闻 |

嗣后**十一月戊辰**，范氏进封**皇贵妃**；**庆陵**享殿告成，光宗神位奉安。

## 十八、孙承宗关外屯守与经抚之争

十月间**孙承宗**抵关，奉**守关大略**长疏，亲阅**前屯—中后所—宁远—觉华**二百里形势，获准便宜调度。

- **五城三十堡**：兵民十余万，可田五千余顷；前屯**赵率教**修城屯田有成，宁远、觉华为必据必争。
- **修筑方略**：拟以三万班军、三年工期、帑金经臣之半，远筑宁远—首山一线，比近修八里铺更能垂利。
- **开屯买牛**：与督抚合算牛种、耕具；渐移关门守具于外，**袁崇焕**同三参将经营宁远。
- **经抚之辩**：屡疏请罢经略、不推总督，或暂归阙下联络中外；又论**登莱抚**不可遽裁、**沈有容**双岛兵额不足；上谕勉留关门，边防正急。
- **车营**：十二月请发帑二十四万编车骑步营，上先给十万。

## 十九、蓟辽督抚更迭与抚夷之祸

| 人物 | 变故 |
|------|------|
| **王象乾** | 以忧闻告归，进少师兼太子太保；后仍命料理蓟辽抚赏，候代离任 |
| **吴用先** | 总督蓟辽；到任历昌蓟及关外宁远，忧关内三协墙台倾圮、新兵未练 |

| **张凤翼** | 任辽东巡抚，疏陈辽民四悯五虑，请收人心、发军需 |
| **仙灵寺之败** | 哈喇慎**朗素贵英**挟赏设伏，中右参将**王楹**战死；孙承宗枭逃将**周继武**等十九人，优恤王楹 |

**赵彦**条陈守关八议：简兵分布、固结人心、鼓舞胆力、固守喜峰等隘口、哨探守台、坚壁清野、抚夷伐谋、海外牵制（**李倧**暂署朝鲜国事协同**毛文龙**）。**朱钦相**、**潘云翼**等又论蓟门修墙、抚赏清查及马世龙、尤世禄将帅不睦。

## 二十、贵州再振与督抚易人

王三善殉节后，黔事改由**蔡复一**总督，**杨述中**督饷。

### 蔡复一「六议」

## 二十九、此段历史脉络（简括）

天启三年**冬**，朝廷以**皇子诞生**与**冬至南郊**两大典仪为轴，铺陈覃恩大赦；然边事并未稍歇：**孙承宗**屯筑宁远—觉华、与**王象乾**抚夷失事（**王楹**之死）交织，**蓟辽总督**去留牵动全局；**贵州**王三善复报大捷而督抚仍争饷权；**四川**朱燮元终擒**奢崇明**；**毛文龙**海外屡捷，**李倧**受封朝鲜国王。南京**陈鼎相**之狱、畿辅**妖党**与**福宁军变**示内地未安；**叶向高**二十一疏乞归、**赵南星**整铨、**魏忠贤**恩荫再增，则中枢权柄与言路之争愈显。至岁末，**屯田**、**裁冗**、**京营清查**并起，而灾异、地震连报，户兵财计仍艰——**天启**政局在「喜事」与「多故」之间愈走愈紧。

## 五十、此段历史脉络（简括）

**天启五年四月至九月**，阉党清洗由「削籍追赃」升级为「诏狱毙命」：**汪文言**狱牵**东林**全案，**霍维华**定谳**三案**、**张讷**毁书院，**刘一燝**/**韩爌**/**赵彦**/**王之采**/**朱延禧**等迭去；**七月****杨涟**、**左光斗**、**魏大中**死于镇抚，**八月**上亲谕「扫清门户」，**熊廷弼**、**蒋应阳**弃市，**魏广微**亦荣归。边事则**孙承宗**坚屯宁远、汰兵省饷六十万，**旅顺**弃守、**盐场口**设哨成定议，**毛文龙**海外屡捷而献俘真伪屡疑；**朱燮元**代**蔡复一**督黔，**沾益**/**曲靖**之战与**安效良**反复，西南仍赖屯田、事例与滇黔协饷。中枢**周如磐**等入阁、**三殿**大工与**荆州**鼓铸并急，而户兵财计、关兵鼓噪、外解拖欠之弊未息——**天启**五年夏秋，「信史」已定、正人几尽，国势内外交困之局愈不可回。
